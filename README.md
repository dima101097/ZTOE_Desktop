# ZTOE Desktop — відключення світла (Житомиробленерго)

Програма для Windows, яка стежить за графіком погодинних відключень на
[ztoe.com.ua](https://www.ztoe.com.ua/unhooking-search.php) для вашої адреси й попереджає заздалегідь:
у Telegram, сповіщеннями Windows, вікном зі звуком і, за бажанням, вимиканням ПК перед відключенням.

> Неофіційна програма: не пов'язана з АТ «Житомиробленерго» і лише читає графік з їхнього сайту.

## Можливості

- графік вашої підчерги на сьогодні й завтра, відлік до вимкнення / включення, графік усіх черг;
- пошук підчерги за адресою (РЕМ → населений пункт → вулиця → будинок) або вибір вручну;
- Telegram (особистий чат, група чи гілка групи): новий і змінений графік, попередження перед вимкненням і включенням,
  беззвучний режим уночі;
- три рівні попереджень: Telegram і сповіщення Windows → вікно поверх усього зі звуком → примусове вимкнення ПК;
- перевірка у фоні через Планувальник Windows — Telegram працює, навіть коли вікно закрито;
- без інтернету або коли сайт не працює — усе призупиняється до відновлення, а не спрацьовує за застарілим графіком;
- значок у треї (зелений / червоний / сірий), автозапуск з Windows;
- автоматичне оновлення з релізів GitHub.

## Встановлення

1. Завантажте `.exe` з [останнього релізу](https://github.com/dima101097/ZTOE_Desktop/releases/latest):
   `ZTOE_Power_x64.exe` — для 64-бітної Windows (майже всі сучасні ПК), `ZTOE_Power_x86.exe` — для 32-бітної.
2. Запустіть. Програма не підписана сертифікатом, тому Windows SmartScreen може показати
   «Windows захистив ваш ПК» — натисніть «Докладніше» → «Однаково запустити».
3. Програма має лежати у власній папці `ZTOE_Power`: поруч з нею зберігаються `config.json`, журнал і кеш адрес.
   Якщо її запущено з іншого місця (наприклад, із «Завантажень»), вона запропонує вибрати, де створити папку
   `ZTOE_Power` (типово `%LOCALAPPDATA%\Programs`), перенесе туди себе й свої файли та запуститься звідти.
   Якщо відмовитися, вона працюватиме там, де лежить, і більше не питатиме.

Одночасно може працювати лише одна копія програми: повторний запуск лише нагадає, що її значок уже в треї.

Потрібна Windows 10 або 11. Python не потрібен.

## Налаштування (5 хвилин)

1. Створіть бота: напишіть [@BotFather](https://t.me/BotFather) у Telegram, команда `/newbot`, скопіюйте токен.
2. На вкладці «Налаштування» вставте токен, напишіть своєму боту будь-яке повідомлення і натисніть
   «Визначити автоматично» — Chat ID (і гілка групи, якщо писали в гілці) підставляться самі.
3. На вкладці «Графік» натисніть «Додати адресу», знайдіть свій будинок (або оберіть підчергу вручну)
   і натисніть «Зберегти». Видалити адресу — значок 🗑 поруч з нею.
4. На вкладці «Попередження» увімкніть потрібні попередження й задайте, за скільки хвилин попереджати,
   і натисніть «Зберегти».

Перевірка у фоні (Планувальник Windows, з періодом із налаштувань) вмикається сама під час запуску програми.
Щоб працювали вікно зі звуком і вимкнення ПК, програма має бути запущена (у треї) — увімкніть
«Запускати програму в треї разом з Windows».

## Як це працює

Програма живе в треї біля годинника: подвійний клік відкриває вікно, хрестик ховає його назад,
«Вийти» в меню значка закриває програму. Значок зелений, коли світло за графіком є, червоний — під час
можливого відключення, сірий — коли немає інтернету або сайт не відповідає.

**Без інтернету** програма не перевіряє графік і нічого не надсилає, не показує вікно попередження й не вимикає ПК:
стан у вікні змінюється на «Немає інтернету», а про втрату й відновлення зв'язку з'являється сповіщення Windows.

**Якщо сайт ztoe.com.ua не відповідає** кілька спроб поспіль, усе так само призупиняється до відновлення сайту,
а в Telegram (якщо це увімкнено) приходить повідомлення про падіння й відновлення сайту.

## Оновлення

Під час запуску програма перевіряє [останній реліз](https://github.com/dima101097/ZTOE_Desktop/releases/latest)
і, якщо є новіша версія, показує, що змінилося, і пропонує оновитися. Після згоди `.exe` потрібної розрядності
завантажується, перевіряється (розмір і SHA-256), підміняє старий і запускається сам; налаштування зберігаються.
Перевірити вручну — «Перевірити оновлення» на вкладці «Налаштування» або в меню значка в треї;
там само можна вимкнути перевірку під час запуску.

## Параметри config.json

Усе це задається у вікні; файл можна правити й вручну (коли програма закрита).

| поле | що означає |
|---|---|
| `subqueue` | ваша підчерга, від `1.1` до `6.2`; порожньо — адресу не вибрано, показується графік усіх черг без сповіщень |
| `remind_off_minutes` | за скільки хвилин попереджати про можливе вимкнення (0 — не попереджати) |
| `remind_on_minutes` | за скільки хвилин попереджати про включення (0 — не попереджати) |
| `windows_notifications` | показувати сповіщення Windows, коли програма працює в треї |
| `telegram_token`, `telegram_chat_id` | дані бота; якщо токен порожній, повідомлення друкуються в консоль |
| `telegram_thread_enabled`, `telegram_thread_id` | надсилати в гілку (тему) групи з темами |
| `telegram_silent` | звук повідомлень: `none` — усе зі звуком, `schedule` — графік беззвучно, `all` — усе беззвучно |
| `telegram_silent_when`, `telegram_silent_from`, `telegram_silent_to` | коли діє беззвучний режим: `always` — завжди, `hours` — лише з `from` до `to` (типово 22:00–07:00) |
| `telegram_site_down` | повідомляти в Telegram, коли сайт ztoe.com.ua не працює і коли відновиться (типово `true`) |
| `check_interval_minutes` | як часто перевіряти сайт на зміни графіка, хвилин (типово 5) |
| `address_cache_hours` | скільки зберігати довідник адрес, годин (типово 24) |
| `check_updates` | перевіряти новий реліз на GitHub під час запуску (типово `true`) |

Приклад — [`config.example.json`](config.example.json).

## Запуск з коду

Потрібен Python 3.9+ ([python.org](https://www.python.org)); для значка в треї — `pip install pystray pillow`.

```bash
python settings_gui.py            # вікно (з --tray — одразу в трей)
python ztoe_notifier.py --show    # графік своєї підчерги в консолі
python ztoe_notifier.py --test-telegram
```

Зібрати `.exe` ([PyInstaller](https://pyinstaller.org)); 32-бітна версія збирається 32-бітним Python:

```bash
pip install pyinstaller pystray pillow
python -m PyInstaller --onefile --windowed --name ZTOE_Power_x64 --icon icon.ico --hidden-import pystray._win32 --exclude-module numpy settings_gui.py
```

## Якщо щось не працює

- Журнал — `ztoe.log` поруч з `.exe`.
- Якщо сайт змінив розмітку: `python ztoe_notifier.py --save-html page.html --show` збереже сторінку —
  додайте її до [issue](https://github.com/dima101097/ZTOE_Desktop/issues), і розбір таблиці можна підлаштувати.
